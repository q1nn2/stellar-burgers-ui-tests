# Sprint_5 — Stellar Burgers UI tests

Автотесты для учебного сервиса Stellar Burgers:
https://stellarburgers.education-services.ru/

## Что проверяется

Регистрация:
- успешная регистрация;
- ошибка при пароле короче 6 символов.

Вход:
- через кнопку «Войти в аккаунт»;
- через «Личный кабинет»;
- через форму регистрации;
- через форму восстановления пароля.

Личный кабинет:
- переход в личный кабинет;
- переход в конструктор по кнопке «Конструктор»;
- переход в конструктор по логотипу;
- выход из аккаунта.

Конструктор:
- переход к разделу «Булки»;
- переход к разделу «Соусы»;
- переход к разделу «Начинки».

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Google Chrome должен быть установлен. Selenium Manager автоматически подберёт драйвер для Chrome.

Перед запуском открой `data.py` и замени `COHORT_NUMBER = 25` на номер своей когорты.

## Запуск

```bash
pytest -v
```

Все локаторы находятся в `locators.py`, фикстуры — в `conftest.py`,
генераторы логина и пароля — в `generators.py`.
