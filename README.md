# Stellar Burgers — UI-тесты

Проект автоматизированного UI-тестирования учебного веб-сервиса **Stellar Burgers**.

Тесты проверяют основные пользовательские сценарии регистрации, авторизации, личного кабинета и конструктора бургеров. Проект написан на Python с использованием Pytest и Selenium WebDriver.

## Что протестировано

### Регистрация
- успешная регистрация нового пользователя;
- отображение ошибки при пароле короче 6 символов.

### Авторизация
- вход через кнопку «Войти в аккаунт»;
- вход через «Личный кабинет»;
- вход через форму регистрации;
- вход через форму восстановления пароля.

### Личный кабинет
- переход в личный кабинет;
- переход из личного кабинета в конструктор;
- переход в конструктор по логотипу Stellar Burgers;
- выход из аккаунта.

### Конструктор
- переход к разделу «Булки»;
- переход к разделу «Соусы»;
- переход к разделу «Начинки».

## Стек

- Python 3
- Pytest
- Selenium WebDriver
- Google Chrome

## Структура проекта

```text
.
├── tests/              # UI-тесты
├── conftest.py         # фикстуры WebDriver и тестового пользователя
├── data.py             # URL и тестовые данные
├── generators.py       # генерация уникальных данных
├── helpers.py          # общие действия для тестовых сценариев
├── locators.py         # локаторы элементов
├── pytest.ini          # настройки Pytest
└── requirements.txt    # зависимости проекта
```

## Подход к тестированию

- тесты сгруппированы по функциональности;
- для ожидания элементов используются явные ожидания WebDriverWait;
- данные новых пользователей генерируются для тестовых запусков;
- WebDriver создаётся и закрывается через Pytest-фикстуру;
- локаторы и тестовые данные вынесены из тестовых сценариев.

## Установка

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS/Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Google Chrome должен быть установлен. Selenium Manager автоматически подберёт совместимый драйвер.

## Запуск

```bash
pytest -v
```
